### System Requirements

| Requirement | Minimum |
|---|---|
| Operating System | Windows 10 or Windows 11 |
| Architecture | 64-bit (x64) |
| Disk Space | ~200 MB |
| Internet | Required for license verification and updates |

## Features

- **32 types** of Bengali land deed documents
- Professional deed output with proper legal formatting
- Built-in templates for all common property documents
- Offline document creation — internet only needed for license & sync
- Automatic updates — new versions install seamlessly
- Local data storage — your deeds stay on your computer

## Installation

1. Download the latest `.exe` from the [Releases](https://github.com/dolil/dolilsheba-releases/releases/latest) page
2. Run the installer
3. Follow the on-screen instructions
4. Launch Dolilsheba from your desktop shortcut

## Updates

Dolilsheba checks for updates automatically when you open the app. When a new version is available, you will see an update notification inside the app. You can also check manually from **Help → Check for Updates**.
